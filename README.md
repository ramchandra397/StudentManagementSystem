# Student Management System

A console-based application to manage student records.

## Tech Stack
Java, JDBC, PostgreSQL, Maven

## Features
- Add, view, search, update and delete students (CRUD)
- Exception handling and input validation
- Layered structure: model, dao, db, main

## Setup
1. Create a PostgreSQL database and a `students` table
2. Update the password in `DBConnection.java`
3. Run `Main.java`
